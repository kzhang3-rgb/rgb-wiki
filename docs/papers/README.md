# 论文收藏

[返回首页](../../README.md)

收集值得反复读的论文（以 arXiv 为主），记录"它解决了什么、结论是否还成立、能不能复现"。**只保留元信息、结论摘要和自己的理解，不镜像 PDF**——论文版面文件体积大、版权归原作者，本地正文摘要比存 PDF 更不容易失效。

本页是索引，每篇论文单独一篇笔记，内容在索引里只保留一行。

## 收录标准

- **以 arXiv ID + 版本号为主键**，标题只作辅助。同一标题在不同年份、不同版本下都可能出现，且 v1 与 v2 的结论可能不同。
- **区分论文自述与我的判断**：论文里的"我们实现了 X 倍加速"是事实陈述，能不能推广到别的场景是判断，两者分开写。
- **标注发表状态**：预印本 / 已被某会议或期刊接收 / 存在官方版本。会议版与预印本结论不一致时，以更新的版本为准并注明差异。
- **不镜像 PDF**，只写摘要与外链；引用注明作者、标题、arXiv ID 与版本。
- **引用量需带来源与核验日期**：arXiv 本身不提供引用数，第三方口径（Google Scholar / Semantic Scholar）差异较大，注明用的是哪一个。
- **有官方代码的项目**：链到 [GitHub 项目收藏](../tools/github-projects/README.md) 下已有的笔记，不重复写一份代码说明。

## 每篇笔记要写清的字段

| 字段 | 说明 |
| --- | --- |
| arXiv ID 与版本 | 如 `2405.12345v3`，主键，必填 |
| 首次提交 / 最近更新 | 用 arXiv 记录页（`arxiv.org/abs/<ID>`）的日期 |
| 作者与机构 | 至少写一作与通讯作者 |
| 发表状态 | 预印本 / 已接收 / 有官方版 |
| 代码与数据入口 | 官方实现、数据集，或注明"未开源" |
| 一句话结论 | 论文自述的贡献 |
| 我的判断 | 适用范围、可疑之处、与已读工作的关系 |
| 是否仍然成立 | 是否被复现、被后续工作取代或推翻 |
| 核验日期 | 仅在实际重看来源后更新 |

## 命名约定

- 文件名为**中文短标题 + 一句话点明贡献**，例如 `FlashAttention-用IO感知把注意力省到线性显存.md`。
- 不把 arXiv ID 写进文件名（同一工作可能有会议版、期刊版多个标识），ID 放在正文元信息表里。
- 具体规则见[编写与维护准则](../../CONTRIBUTING.md)。

## 目录组织

现在**先平铺**，不预建空分类。收满约 20 篇后，再按下方的方向拆成子目录（`papers/llm/`、`papers/systems/` 等），届时本页的索引分组保持不变。

收录按四个方向归类，一篇论文只选一个**主要方向**，跨方向时在笔记的"相关笔记"里互链，不做双份正文：

### 大模型与 Agent

- [Attention Is All You Need：用纯自注意力取代循环与卷积的 Transformer](Attention-Is-All-You-Need-纯自注意力取代循环与卷积的Transformer.md)（`1706.03762v7`）：提出 Transformer 的原始论文，已发表于 NeurIPS 2017；本文重点是自注意力的算法、多头机制与位置编码，以及第 4 节的复杂度对比。**注意 arXiv v7 与会议版报的 BLEU 分数不同**（28.4 vs 27.5），引用数据须注明版本；论文本身未提供官方实现，`tensor2tensor` 已归档。核验于 2026-11-03。
- [生成式 AI 基础小书：从 PCA 到扩散模型的推导路线](生成式AI基础小书-从PCA到扩散模型的推导路线.md)（`2605.29713v2`）：195 页的生成式模型数学基础读本，按"数学自然展开"的顺序串起 PCA、概率 PCA、VAE、扩散、流模型、自回归、GAN 与能量模型；面向基础而非前沿，arXiv 默认许可（无第三方复用授权），未开源。核验于 2026-11-03。
