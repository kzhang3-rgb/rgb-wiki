## 核心结论

这是一个个人收集的"越狱"提示词仓库，目标是绕过各模型自身的安全限制。内容以系统提示、`AGENTS.md`、Modelfile 等形式存在，覆盖 DeepSeek、GLM/ZCode、GPT-oss、Grok、Kimi、Qwen、Gemma、Sonnet、Opus、Muse 等模型，部分文件的提交说明与成人或暗黑题材的小说创作相关。

它没有程序代码，也没有标注开源许可证。

## 使用前需要注意

- **未标注许可证**：默认保留所有权利，整篇转载或再分发存在版权问题，也不适合放进本仓库附件目录。
- **属于提示词注入类内容**：把这些文件当作 `AGENTS.md` 或系统提示贴进带文件和终端权限的编码助手，相当于让来源不明的指令进入本机工作环境，有被引导执行意外操作的风险。
- **可能违反服务条款**：多数模型提供方禁止绕过安全限制，使用可能导致账号受限。
- **容易失效**：越狱提示通常随模型版本更新而失效，仓库本身也在不断跟进版本。
- 我未使用过其中任何文件，实际效果和安全性均未验证。
