## 核心结论

`1c7/chinese-independent-developer` 是一份**聚合中国独立开发者项目的清单**，由作者 `1c7` 从 **2017-09-21** 开始维护至今，README 里能看到"2026 年 11 月 5 号添加"这样的按日更新记录——**近十年持续更新，目前 62,007 Star / 5,575 Fork**。

它是**内容产品（清单），不是可运行的工具**：仓库主体就是一份不断膨胀的 Markdown 列表。

三点先要看清：

1. **入选标准很明确**：README 写明"**必须是网站或 App，不能是开发者工具或论坛型网站**"——所以程序员工具、游戏这类被拆到了**子版面**。
2. **README 已大到需要分册**。主 README **约 320 KB**，因此把"2018 ~ 2025 年收录的项目"单独分出一册，另有"程序员版面""游戏版面"两个子页面。
3. **无 LICENSE**。仓库未见 LICENSE 文件（API `license` 与默认分支检测均为空），**默认保留所有权利**。

## 内容结构

- **项目状态三态**：`:clock8:` 开发中、`:white_check_mark:` 已上线、`:x:` 已关闭或缺乏维护——每条目都带状态标记。
- **按日归档**：清单以"某年某月某日添加"分节，每条含作者署名 + GitHub 主页链接 + 产品链接 + 一句话介绍。
- **"写好一句话产品介绍"的规范**（README 专门强调并给了 `CONTRIBUTING.md`）：反例 `AI 视频生成工具`，正例 `无需剪辑经验，3 步生成竖屏短视频`——**要求写"能力/体验"，而不是写"品类"**。
- **收录方式**：提 Pull Request 或 Issue 自助添加。

## 使用前需要注意

- **无许可证**：清单内容默认保留所有权利，转载/二次利用需谨慎。
- **默认分支是 `master`**：拼接文件链接时注意，别想当然用 `main`。
- **主 README 约 320 KB**：是一个"单文件巨型列表"，网页端打开、克隆与增量维护成本都偏高；且条目会随时间继续膨胀（已被迫分册）。
- **列表质量参差**：收录标准只看"是不是网站/App"，**不代表产品可用、可靠或已盈利**；状态标记由提交者自报，未经验证。
- 我**未逐条点开任何产品、未核验任何项目是否仍在线**：以上为 README 结构与元数据信息。
