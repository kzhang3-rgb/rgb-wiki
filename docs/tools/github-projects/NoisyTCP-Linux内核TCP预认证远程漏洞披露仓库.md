## 核心结论

**一句话定位**：这是一份关于 **NoisyTCP（CVE-2026-99288）** 的**安全公告（security advisory）**，作者 @v4bel 自报已上报并已修补。公告将其定性为 **Linux 内核 TCP 预认证远程破坏（Pre-auth Remote Corruption）**；禁运期结束后（上报至 `linux-distros@vs.openwall.org`）文档公开发布。

**五个要点：**

1. **仓库不是工程，是一篇文章**：`main` 分支只有 **1 个文件（`README.md`）**；**无代码、无 `LICENSE`、0 Release、1 位贡献者**。定位就是"把公告放到 GitHub 上"。
2. **性质与影响**：据公告，漏洞可在**默认配置**下对 "plain" TCP 监听服务（如 Nginx / Apache / SSH）触发，**无需认证、可远程**；公告称**远程 DoS "不难达成"**，而**远程 RCE "目前还没有通用的"**——作者自称只写了针对 VM、实验室专用的有限利用，仍在研究通用利用。
3. **潜伏时间与影响面**：公告给出影响区间为 引入 `079096f103fa`（2015-10-03）→ 修复 `4e2b3ef19e0e`（2026-11-03），称其在 Linux 内核中**潜伏约 11 年**、影响"几乎所有 Linux 发行版"。
4. **触发前提（高层）**：需要**两个或以上 RX 队列，或启用 RPS** 的环境，利用 IPv4 分片与普通 TCP 包在**接收哈希**上的差异，把处理摊开到不同 CPU；需要一个 RX 上下文插在两个检查点之间。**触发窗口很窄**——QEMU/KVM 上默认配置的 Nginx / Apache / SSH 约 **5 秒 ~ 2 分钟**可触发；**安静裸机（8 RX 队列）约需 14 小时**。
5. **缓解**：优先打 `4e2b3ef19e0e` 补丁；若不能立即打，临时缓解为**关闭 SYN cookies**（`net.ipv4.tcp_syncookies=0`，**会削弱 SYN flood 防护**，且按网络命名空间各自设置）或**把接口降到单一 RX 队列并关闭 RPS / RFS**。

**个人判断（未验证）**：作为"内核网络栈竞态漏洞如何写成一份对外公告"的**结构样本**，它可读；但**内容全部来自作者自述**，我未复现、未核对上游补丁。
