# US_Stock_Crash_Monitor：美股风险监测面板

> 记录它的六因子评分方式，以及那些"把不确定性摆在明面上"的设计——这是这个项目最值得借鉴的部分。

- 状态：草稿
- 最近核验：2026-10-30（阅读仓库 README、数据源表与目录结构，未安装运行）
- 适用范围：Python 3.10+，Streamlit 本地面板（`localhost:8501`）；可选 FRED API Key

## 核心结论

一个用六因子观察美股风险的本地面板：巴菲特指标、席勒市盈率、信用利差、美债利差、均线乖离、恐慌贪婪。技术栈是 Python + Streamlit + Plotly，监测标的固定为 VOO（标普 500 ETF），强调"可解释"——每个读数来自哪里、哪些因子参与评分、权重如何归一化、共振和红线如何改变总分，都能在界面里核对。

**最需要先知道的一点**：作者在 README 开头就写明"评分衡量规则模型中的风险信号，**不是未来崩盘概率**；历史压力对比使用近似情景参数，**不是回测**"。

## 六因子与默认权重

| 因子 | 默认权重 | 主数据源 |
| --- | --- | --- |
| 巴菲特指标 | 15% | GuruFocus |
| 席勒市盈率 | 20% | Multpl |
| 信用利差（高收益债） | 20% | FRED `BAMLH0A0HYM2`（需 key） |
| 美债利差（10Y / 2Y） | 20% | yfinance `^TNX` / CNBC |
| 均线乖离 | 15% | yfinance ETF 复权日线 |
| 恐慌贪婪指数 | 10% | CNN dataviz |

风险区间：`<60` 较低、`60–<80` 风险累积、`≥80` 高风险。信用因子用近 5 年实际观测的历史分位数，其他因子仍用经验阈值。

权重不必凑成 100%，设为 0 的因子会退出加权、共振与红线规则，其余因子重新归一化。

## 数据源与失败处理

README 给了完整的降级链，值得记下来：

| 指标 | 失败处理 |
| --- | --- |
| ETF 复权日线 / 200 日均线 | 标记为**演示行情**，不计入技术评分或正式历史 |
| 10Y 收益率 | CNBC → 东方财富 → FRED → 缺失/手动 |
| 2Y 收益率 | 东方财富 → FRED → 缺失/手动 |
| 信用利差、巴菲特指标、席勒市盈率、恐慌贪婪 | 缺失或手动校准 |

作者还提示第三方站点可能限流、拒绝访问或更改结构，且"数据源状态代表获取结果，不保证所有读数都为同一时刻；行情为复权日线，不是盘中实时报价"。

## 值得借鉴的设计

这个项目在"如何处理不可靠数据"上做得比大多数同类工具清楚，有三点可以直接借鉴到自己的笔记和项目里：

- **缺失就保持缺失**：抓取失败时不做静默填充、不用预设值顶替。预设值只作为手动输入的起始值，不自动参与评分。
- **三类数据严格分层**：真实行情、演示数据（固定随机种子）、手动覆盖，在界面上分别标注；**只有"行情真实 + 已启用因子完整 + 无手动覆盖"三条同时满足**才写入正式历史，手动、缺失和演示数据不会覆盖自动记录。
- **口径全程可追溯**：历史记录按行情日期、标的、模型版本与权重配置隔离保存，同一行情日期只保留最新评分（周末不会凭空多出一个交易日），不同模型和权重分别展示趋势。写入用原子写加锁。

这几点和本 wiki 一直坚持的"区分事实、判断与未验证内容"是同一个思路：**不是让数据看起来完整，而是让读者知道哪里有缺口。**

另外它单独写了一节"模型边界"，主动列出局限，包括：均线乖离和情绪评分偏向识别过热，**不完整覆盖正在发生的下跌，深度负乖离得低分不能推断市场安全**；正利差的小幅平坦区间仍用经验分数，当前快照无法证明此前曾倒挂；压力对比统一使用信用绝对阈值，可能与主仪表盘的历史分位数评分不同；估值、信用与情绪反映全市场背景，并非 VOO 独有指标；历史只能在应用被打开且数据完整时积累，没有后台采集或通知。

## 使用前需要注意

- **不是崩盘预测，也不是回测**：作者明确说明评分是规则模型的风险信号，历史压力对比用的是近似情景参数。已有"真实回测"列入待选功能清单，但**尚未实现**。
- **至少要配一个 FRED API Key 才完整**：不配置时信用利差因子会一直缺失（可手动输入或把权重设为零），评分会变成"参考评分"。
- **数据源依赖多个第三方站点**：yfinance、CNBC、东方财富、GuruFocus、Multpl、CNN，都有限流和改版风险，属于这类工具的结构性弱点。
- **监测面窄**：只盯 VOO 一个标的，且均线乖离、情绪等因子本身偏"过热识别"，对已经在下跌的行情反应有限。想覆盖更多标的要自己改。
- **历史上限取决于你打开应用的次数**：没有后台采集，不打开就不记录。
