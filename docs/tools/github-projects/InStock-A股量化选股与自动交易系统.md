# InStock：覆盖"抓数 → 指标 → 选股 → 回测 → 自动交易"的 A 股量化系统

> 一个 2023 年就起步、**Star 超 1.5 万**的 A 股量化"全家桶"：抓取每日行情 / 资金流 / 龙虎榜，用 TA-Lib 算指标与筹码分布，识别 61 种 K 线形态，跑综合选股与策略回测，还带**基于同花顺客户端 GUI 的自动交易**。值得记的不是功能多，而是三件使用前必须看清的事：**它自述"本系统中的表格为第三方商业控件，仅使用了评估版"**（授权边界不清）；**README 的安装说明里挂了 Navicat 破解补丁的网盘链接**；**它建议用代理池 + Cookie 注入来绕开东财的抓取限流**——这本身就是"规避对方风控"的做法。**未安装、未运行、未接数据源、未执行任何交易**。

## 核心结论

**一句话定位（描述）**：`获取股票数据,计算股票指标,筹码分布,识别股票形态,综合选股,选股策略,股票验证回测,股票自动交易,支持PC及移动设备。`——README 自称"InStock 股票系统"，定位是"量化投资的好帮手"，强调**运行高效**（自述普通笔记本跑完一天全流程约 4 分钟，指标结果对齐同花顺 / 通达信）。

**① 它是什么。** 一套**单机自托管的 A 股全流程系统**：抓每日股票与 ETF 数据 → 算技术指标与筹码分布（CYQ）→ 识别 K 线形态 → 综合选股 / 内置策略选股 → 回测验证 → 自动交易；结果用一个本地 Web 界面（默认 `http://localhost:9988/`）可视化，支持 PC / 平板 / 手机，也提供 Docker 镜像。

**② 数据落 MySQL，网页按"视图字典"自动生成。** README 明确"存储采用数据库设计"，自动建库建表并封装批量更新 / 插入；前端"添加新业务表单只需配置视图字典即可自动出现可视化界面"。这套"配置驱动生成页面"的做法，是它宣称"方便扩展"的主要依据。

**③ 自动交易是它最敏感的一块，且作者自己踩了刹车。** README 的原话："支持自动交易，内置自动打新股的策略及示例策略，**由于涉及金钱，规避可能存在风险，没有提供其他交易策略**。"实现方式是 **Windows + 同花顺客户端 + Tesseract 识别验证码**（对客户端 GUI 做自动化）。README 另提醒"交易日 10:00 点会触发打新"。

**个人判断（未验证）**：这个仓库可以被读成"**十来年老派的 Python 单机量化方案**"——纯 Python + MySQL + Web，而不是现代数据栈（Polars / DuckDB / Parquet）。它的价值更多在**完整度与流程覆盖**（从取数一直到下单），而不是工程精细度；但正因为它把"自动交易"和"绕风控抓数"都做进了同一套系统，**授权、合规与资金安全三方面的风险都比纯分析工具高一档**。

## 功能范围（README 自述）

README 列了十六个功能板块，按"取数 → 计算 → 选股 → 验证 → 交易 → 展示"排列，摘要如下：

| 板块 | 一句话 |
| --- | --- |
| 综合选股 | 股票范围 / 基本面 / 技术面 / 消息面 / 人气指标 / 行情数据 **六个大类、200 多个栏目**自由组合 |
| 每日数据 | 每日行情、资金流向、分红配送、龙虎榜、大宗交易、基本面、行业 / 概念资金流、早盘抢筹、尾盘抢筹、涨停原因、ETF 数据 |
| 指标计算 | 基于 **TA-Lib + pandas** 算 **32 类**技术指标（MACD / KDJ / BOLL / RSI / DMI / CCI / OBV / SAR …），README 自称"结果与同花顺、通达信一致" |
| 买卖判定 | 按 KDJ / RSI / CCI / CR / W%R / VR 的超买超卖区间给买卖提示 |
| K 线形态 | 识别 **61 种** K 线形态，支持自选形态；输出"负 = 卖出信号、0 = 未出现、正 = 买入信号" |
| 筹码分布 | 计算一定时间范围内最高 / 最低价与成交量，输出**价格—成交量占比分布**，缺省 210 个交易日，可与东方财富等软件对照 |
| 策略选股 | 内置放量上涨 / 均线多头 / 停机坪 / 回踩年线 / 突破平台 / 无大幅回撤 / 海龟交易法则 / 高而窄的旗形 / 放量跌停 / 低 ATR 成长 / 基本面选股等策略，另留策略模板 |
| 选股验证 | 对指标与策略选出的股票做**回测**，验证成功率 |
| 自动交易 | **内置打新股策略 + 示例策略**；有交易日志，可按策略配置日志；README 明确未提供其他交易策略 |
| 关注 / 批量 | 支持自选关注置顶标红；支持区间 / 枚举 / 当前时间批量作业，并"智能识别交易日" |
| 代理与 Cookie | 支持**多代理**取数（`proxy.txt`）与**注入东方财富 Cookie** |
| 存储与展示 | 数据落数据库（自动建表、封装批量更新插入）；Web 界面按"视图字典"自动生成 |
| 效率与日志 | 自述多线程 + 单例共享资源，一天全流程约 4 分钟；日志分 `stock_execute_job.log` / `stock_web.log` / `stock_trade.log` |

## 使用前需要注意

- **✅ 许可证本身干净**：`LICENSE` 是**完整 Apache 2.0 原文**、无附加限制条款，shields 也识别为 `Apache-2.0`——这一点比很多同类项目清楚。（对照：[tick-stock-panel](tick-stock-panel-自托管A股量化工作台.md) 的 README 声称"严禁商用"却用 MIT；[easy-stock](easy-stock-A股AI智能投研工作台.md) 用的是 PolyForm 非商用。）
- **⚠️ 但依赖里有"第三方商业控件（评估版）"**：README"特别声明"原文——"**本系统中的表格为第三方商业控件，仅使用了评估版进行学习及测试**"。**评估版控件用于生产或长期使用可能触及授权问题**，且这一条与 Apache 2.0 并不冲突（许可证只覆盖本仓库自有代码），需要使用者自行厘清。
- **⚠️ README 的安装说明里挂了「Navicat 破解补丁」网盘链接**（"安装 Navicat（可选）"一节）。这是**推广使用盗版软件**的做法，存在法律与安全风险，**不建议照做**。
- **⚠️ "代理池 + Cookie 注入"本质是绕开对方风控**：README"支持代理及 Cookie"一节开宗明义——"很多网站对大量请求有防护机制……代理 IP 能够帮助分散请求来源，避免单一 IP 被封锁"，并给出东财 Cookie 的获取与轮换步骤。**这是对第三方站点的规避行为**，是否违反目标站点的服务条款、是否涉及数据合规，**由使用者自行评估**。
- **⚠️ 自动交易资金风险 + 券商条款风险**：内置交易走"**同花顺客户端 + Tesseract 验证码识别**"的 GUI 自动化，README 自己都写"由于涉及金钱，规避可能存在风险，没有提供其他交易策略"。**委托下单是真实资金操作**，除策略亏损外，还可能违反券商客户端的使用条款。
