# Seedance 真人感分镜生成器：把故事做成"真人实拍质感"AI 短剧的技能包

> 记录一个**把"故事 → 剧本 → 生图提示词 → 视频提示词 → 成片"整条流程固化成技能**的中文技能包（`liangdabiao/seedance-storyboard-generator-realman`，自述"真人实拍质感 AI 短剧分镜生成器"）：它和普通分镜工具最大的差别是**刻意追求"真人实拍质感 + 电影感"，而不是卡通 / 动画 / 塑料感**，并把"真人感"拆成"**六根支柱**"写进提示词。三条先记住：**它依赖"即梦 CLI"（`dreamina-canvas`）才能真正出图 / 出片**；**关键顺序是先出资产图锁形象、再生成视频**；**仓库极新（2026-11-16 创建）且无 LICENSE**。未安装、未登录即梦、未生成任何素材。

## 核心结论

**一句话定位（API 描述）**：**"真人实拍质感 AI 短剧分镜生成器"**——"一个帮你把故事 / 剧本变成真人实拍质感 AI 视频的技能包""你给它一个故事，它帮你走完从剧本到成片的全过程，而且生成的画面尽量像真人拍的电影。"

**① 它是一条四步流水线："文 → 资 → 视 → 剪"。**

| 阶段 | 做什么 | 产出 |
| --- | --- | --- |
| **文** | 把故事写成剧本、分集 | `XX_剧本.md` |
| **资** | 给角色 / 场景 / 道具写生图提示词，做出参考图 | `资产提示词.md` + 资产图 |
| **视** | 用参考图写视频提示词，生成视频片段 | `E0X_Seedance提示词.md` + 视频 |
| **剪** | 把片段拼成成片 | 成片 mp4 |

README 把"**关键顺序**"单列：**一定要先出资产图（资），再用它当参考生成视频（视）；跳过"资"会导致每集人物换脸、场景漂移。**

**② 它最大的差异点是"真人感六根支柱"。** README 说普通提示词容易写成"电影级、高级感"这种空话、模型看完还是出卡通脸，于是把"真人感"拆成 6 个**能直接写进提示词**的具体维度：

| 支柱 | 意思 |
| --- | --- |
| **摄影介质** | 写具体胶片、颗粒、光位，不写空泛形容词 |
| **皮肤与材质** | 写不完美的小细节（毛孔、瑕疵、碎发、褶皱、粉笔灰） |
| **空间锚定** | 写具体距离和站位 |
| **物理因果** | 动作要有发力与受力，不许瞬移 |
| **呼吸微表情** | 用生理变化代替抽象情绪词 |
| **同期声口型** | 台词逐字写在角色说话那一刻，声音段统一声明口型 |

这些规则的**唯一事实来源**是 `references/真人感电影写实指南.md`（README 原文标注）。

**③ 默认配置与成本（README 列）。** 生图默认 **Seedream 5.5**、生视频默认 **Seedance 2.5 flash**；**视频默认 480p**（README 给参考：**15 秒约 105 积分；720p 约 285 积分**）；画幅按题材定（室内双人对话 16:9、短视频 9:16）；**生成前会先用免费报价接口算这一批要花多少、报给用户确认后再跑**（"不会偷偷刷卡"）。

**④ 它自带一个完整案例。** `example/` 放了一个"**从零到成片的完整案例**"：费曼《不一样的工具箱》——普林斯顿数学系攻不破的一道积分被费曼用"积分号下求导"当场解开；**5 集 × 15 秒、单场景、成片已生成**（B 站有链接）。`example/` 内含剧本、资产提示词、资产图、分镜提示词（存档版 + 纯提示词版）、成片抽帧。README 说明**成片 mp4 不随仓库分发**。
