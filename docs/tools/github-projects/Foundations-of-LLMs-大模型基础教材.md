## 核心结论

浙江大学 ZJU-LLMs 团队写的《大模型基础》开源教材，第一版六章，覆盖传统语言模型到大语言模型架构、Prompt 工程、参数高效微调、模型编辑和检索增强生成。仓库里放的是完整版 PDF、分章节 PDF、配套论文列表，以及英文版。

内容定位偏"系统讲解基础 + 介绍前沿"，每章配一份 Paper List 便于追进展。

**使用前最需要知道的一点是许可**：这份教材采用 **CC BY-NC-ND 4.0**，即署名、非商业性使用、**禁止演绎**。不能商用，也不能改写、翻译后重新发布。

## 六章内容

| 章 | 主题 | 主要小节 |
| --- | --- | --- |
| 1 | 语言模型基础 | 统计方法、RNN、Transformer、采样方法、评测 |

## 使用前需要注意

- **许可限制最要紧**：CC BY-NC-ND 4.0 禁止商用、禁止演绎。想摘录、改写或翻译后发布都要先确认协议要求。
- **"月度更新"的声明与现状不符**：README 写明"持续进行月度更新"，但实际目录最后更新时间是——教材与分章节 PDF 2024-12-04、英文版 2024-11-29；最近一次提交（2025-12-12）只改了 README 里的新闻部分。也就是说正文内容约两年没有实质更新，把它当作一本已定稿的第一版来读更合适。
- **覆盖面到 RAG 为止**：README 提到后续会补推理加速、大模型智能体方向，但仓库里目前没有对应章节。想学这两块要另找资料。
- **没有 Release 也没有 Tag**：PDF 直接从 `main` 分支取，引用时最好记录你拿到的具体提交。
- 我只读了 README、目录和许可证，没有下载 PDF 正文，内容质量与准确度未作评估；文中提到"如有谬误请提 issue"，说明作者也预期存在待勘误之处。
- 关注度数据口径提醒：同一时间 GitHub API 返回 18,367 Star，页面显示 16.3k，本笔记采用带时间戳的 API 数据。
