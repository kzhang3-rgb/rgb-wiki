## 核心结论

一个免 Root 修改 SIM 卡国家码的 Android 工具，用来解决国际漫游兼容性问题、让部分按地区限制的应用可用。

关键实现方式：它调用 Android 系统级 API（`CarrierConfigLoader`）修改**系统内的运营商配置参数**，**不修改 SIM 卡本身**，不依赖 Xposed / Magisk 等框架，只需要 Shizuku 提供权限。所有修改可逆。

## 它解决什么问题

README 列的典型场景：

- 手机无法正确识别运营商配置、运营商特定功能无法使用；
- 漫游时运营商名称显示异常、网络配置与漫游地不匹配；
- **TikTok 提示网络错误、功能不完整**——把国家码改成支持的地区（如 JP、US）后重新打开即可；
- **Samsung Health 无法通过首次 SIM 卡检测**、健康数据无法同步。

我把它归类为"按地区限制的服务"这一类问题的绕行手段，和之前记的分流规则、网络工具是同一类需求的不同层面。

## 使用方式

推荐用随仓库发布的**快速启动工具**：

1. 手机上打开开发者选项，开启 USB 调试、USB 调试（安全设置）和 USB 安装；
2. 数据线连电脑并授权；
3. 运行快速启动工具，它会自动检测设备、安装 Shizuku 并引导启用，再自动安装 Nrfr 应用；
4. 在手机上打开 Nrfr，选择 SIM 卡、设置目标国家码、应用。

修改后无需重启，立即生效且重启后保持；要还原用应用内的还原功能。

## 使用前需要注意

- **会改动运营商配置的读取结果**。README 自己提示"修改国家码可能会影响运营商服务，请谨慎操作"，并且"部分设备可能不支持"。属于会改变系统行为、需要记得怎么还原的操作。
- **用途本身涉及服务条款判断**。它的定位就是"解锁运营商限制、突破区域限制"，能不能这么做取决于你使用的运营商与服务的条款，这部分作者没有讨论。
- **需要长期开启 USB 调试**。快速启动工具依赖 USB 调试与 USB 安装权限来完成自动部署，装完后是否关掉要自己权衡。
- **依赖 Shizuku，而 Shizuku 自身也有维护状态**：这是一个需要单独安装并保持运行的外部组件，它停更或与新系统不兼容时，这个工具会一起失效。
- **上游已停更约一年**，114 个开放 Issue 基本无人处理。在新版 Android 或新机型上能否工作，需要自己验证。
