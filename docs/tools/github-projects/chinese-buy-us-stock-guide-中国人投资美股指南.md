## 核心结论

一份写给中国大陆投资者的美股科普，九篇正篇加一篇加更，按"先搞懂规则 → 再把钱投进去 → 最后安全取回来"的顺序展开：开户、税务、合规、美国券商、银行入金、加密入金、出金、美国税号、总结。

它比较有价值的地方是**顺序安排**：作者建议新手先读税务和合规两篇，搞清楚国家怎么征税、自己能接受多大风险，再去开户。多数同类攻略直接从"哪家券商返佣高"讲起，这份反过来先讲规则约束。
