# KHunter：A 股量化选股系统

> 记录它的功能范围与技术栈，以及"形态选股策略有效性"这件事在项目里并没有被验证。

- 状态：草稿

## 核心结论

一套面向个人投资者的 A 股选股系统（作者称"形态猎手"），链条比较完整：数据获取 → 11 种选股策略 → 4 种择时策略 → 五维评分排名 → 风险过滤 → 回测 → Web 界面查看与管理。数据存 SQLite，Web 界面上线在 `localhost:5001`。

它的定位是**技术形态识别**：策略全部是 K 线组合与经典技术指标（启明星、多方炮、W 底、仙人指路、均线/KDJ/MACD 金叉共振、布林带、RSI、海龟等），没有涉及财务建模或因子研究。

## 主要功能

**五维评分模型**（README 给出的权重）：

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 技术面 | 35% | 策略命中情况，权重累加 |
| 资金面 | 35% | 资金流向分析，README 标注为"最重要指标" |
| 基本面 | 10% | 财务指标分析，以排雷为主 |
| 板块强度 | 10% | 所属板块表现 |
| 事件驱动 | 10% | 重大事件催化 |

**11 种选股策略**：底部趋势拐点、涨停回马枪、涨停横盘、启明星、多金叉共振、多方炮、阻力位突破、强势洗盘弱转强、趋势加速拐点、仙人指路、W 底。

**4 种择时策略**：布林带、RSI、支撑位、海龟。

**其他**：自动排除 ST 股 / 退市股 / 市值过低 / 近期涨幅过高的风险过滤；回测模块（收益率、胜率、最大回撤、交易记录、收益曲线）；为入选股票生成 K 线图；策略参数可在网页上在线调整。

## 使用流程

```bash
git clone https://github.com/ling-0729/KHunter.git
cd KHunter
pip install -r requirements.txt
python main.py web        # 或 Windows 下双击 start.bat
```

README 说明的完整流程是：**初始化数据 → 每日收盘后增量更新 → 执行选股 → 五维评分排名 → 按分数阈值/跟踪天数/支撑位筛选 → 进入"狩猎场" → 追踪与回测迭代参数**。

扩展自定义策略的方式是继承 `BaseStrategy`、实现 `calculate_indicators()` 与 `select_stocks()`，再到 `config/strategy_params.yaml` 加参数，系统自动识别。这个扩展点设计得比较清楚。

另外 README 提到：如果没使用 tushare，本版本提供更简易的方式，功能够用但评分会缺少其他维度的数据。

## 使用前需要注意

- **策略有效性没有被验证**：11 种策略都是传统技术形态与指标，项目未提供任何样本外测试、实盘结果或收益数据。作者的免责声明也写明了"筛选结果仅为技术指标计算结果，不代表对任何股票的推荐或预测""过往表现不代表未来收益"。
- **回测结论不等于实盘**：模块提供了收益率、胜率、最大回撤等指标，但我未阅读代码，无法确认其是否计入手续费、滑点与复权处理差异。想用于实盘前建议先自己核对回测假设。
- **数据源依赖 akshare 免费数据**：数据质量与可用性取决于上游，且 A 股行情接口常有限流与变更。
- **"资金面 35% 权重"值得留意**：README 把它标为最重要指标，但免费数据源能否提供可靠的资金流数据我未验证。
- **这是投资决策工具，不是投资建议**：即使评分再完整，最终仍由使用者独立判断；作者声明的 5 条免责条款也强调不承担投资损失。
- 我未安装运行，未验证数据获取、选股结果与回测输出是否正常。
