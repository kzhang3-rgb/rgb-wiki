## 需要明确的一点：书籍 PDF 的版权状况

仓库根目录直接上传了上述书籍的 **PDF 全文**（如《证券分析》《聪明的投资者》《股市长线法宝》等），仓库 134 MB 的体积主要来自这些文件。

这些是**仍在售的商业出版物**，版权属于原作者与出版社，上传者不具备分发权。仓库本身也没有附任何许可证。

因此：

- 本笔记**只记录书名、作者与评分等书目信息**，不转载、不下载、也不镜像其中任何内容，并在下方只给出仓库地址。
- 这类仓库随时可能因版权投诉被下架或删除，**不适合作为长期依赖的来源**。要看这些书，正规渠道购买或借阅更稳妥，也更完整（PDF 常有缺页、扫描质量差、版本不明的问题）。
- 顺着这类清单找资源时，建议把"书名"当作唯一的有效信息，其余部分自己另找。

这一条同样对应本 wiki 的规则：记录"有哪些值得看的东西"，而不是把别人的内容搬进来。

## 其他观察

- **用 Git 仓库分发大体积 PDF 并不合适**：十几本扫描书把仓库撑到 134 MB，每次克隆都要拉全部二进制内容，而 Git 对二进制文件既无法有效压缩也无法增量存储，版本历史对它们没有意义。
- **部分在线播放地址指向第三方影视聚合站点**，这类站点的内容授权状况不明，链接也容易失效。纪录片中真正稳定的做法是记录片名与出品年份，自己去正规平台找。
- **YouTube 频道点评主观性很强**：README 里包含"嫩了一些""装腔作势"这类明确个人评价，也有对具体博主预测能力的判断（例如某位博主对某只股票的价位预测）。这类内容随时间失效很快，且属于作者个人观点，不是事实。
- **"star 后面会持续更新"与实际不符**：README 这样写，但仓库只有 6 次提交、主体内容自 2023 年上传后基本未变。
- 我未访问仓库中的任何外链，也未验证书目信息与豆瓣评分是否准确。
