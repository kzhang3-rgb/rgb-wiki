## 核心结论

一个纯本地的网文写作桌面软件，把"写作 + AI 辅助 + 榜单参考"放在同一个应用里。定位里最关键的三句话是：数据全部存本机（桌面版就是一个 SQLite 文件）、AI 用你自己的 API Key（BYOK）、提示词是可直接编辑的本地 md 文件。

作者说明它"由长期线上运营的写作平台客户端改造而来"，编辑器和章节管理经过真实作者日常使用打磨，主要面向起点、番茄、七猫、晋江等平台的作者。

## 三件核心功能

### 1. 写作

- 富文本编辑器（TipTap），卷/章目录树、拖拽排序、全书搜索、查找替换。
- 边写边存：160ms 本地落盘 + 关窗快照，异常退出重开即恢复。
- 每章自动保留历史版本，可随时回看恢复。
- 参考资料五件套：大纲、角色（含关系图画布）、设定、时间线、故事线（思维导图画布）。
- 书架支持多作品管理、分组、封面、TXT/JSON 导入导出、回收站。
- 码字统计区分手写与 AI 产出，含趋势图、码字日历、连续天数。

### 2. AI 辅助（需自备 API Key）

- 划词工具：润色、扩写、纠错、自定义指令，可采纳可废弃。
- 续写补全：快捷键整拍续写（流式写入正文）+ 打字时的幽灵字建议（Tab 采纳）。
- 妙笔对话、工作流一键建书（灵感 → 大纲 → 设定 → 建书 → 逐章生文，断点可续）。
- 竞品拆书：TXT 整本导入，逐章拆解节奏与卖点，含黄金三章深析。
- AI 调用账本：记录每次调用的场景、字数、Token 和成败原因。

模型可配 DeepSeek、通义千问、智谱、Kimi、OpenAI 等，也支持多数 OpenAI 兼容接口；Ollama、LM Studio 等本地部署模型同样可用，API Key 留空即可。

### 3. 榜单风向

内置爬虫用**你自己的网络**抓取起点、番茄、七猫等 80 多个源，数据只存本机，支持趋势分析、标签风向、CSV 导出和 AI 解读。

## 数据与隐私设计

这部分是它和在线写作平台最本质的区别：

- **全部存本机**：桌面版是一个 SQLite 数据库文件。
- **自动备份**：定时导出为 txt + json，默认放在「文稿」目录，可随时整本导出。
- **提示词全开放**：AI 提示词是本机 md 文件（默认在「文稿/易创提示词」），界面里可视化改或直接改文件，每个场景的采样温度都能调。
- **无需注册登录**：基础写作功能可离线使用。
- **API 请求直连**：Key 存本机，请求从你的电脑直接发往所配置的模型服务商。

## 安装与上手

安装包在 [Releases](https://github.com/yilujian/easy-writing/releases) 页面下载：

- **macOS**：`.dmg`。应用目前未做苹果签名公证，若首次打开提示"已损坏/无法验证开发者"，需要在终端执行 `xattr -cr /Applications/易创.app`。
- **Windows**：`.exe` 安装程序。SmartScreen 拦截时点"更多信息 → 仍要运行"。

上手三步：建书直接开写（不需要配置）；要用 AI 就到「模型管理」选服务商预设、填自己的 Key、测试连接；提示词不合口味在「提示词管理」里改，可恢复默认。

## 使用前需要注意

- **安装包未做代码签名**：macOS 需要手动 `xattr -cr`，Windows 可能被 SmartScreen 拦截。请确认安装包来自本仓库，不要从第三方站点下载。
- **AGPL-3.0 是传染性协议**：如果改造后对外提供服务，需要一并开源。
- **内置爬虫需要留意**：榜单功能会用你的网络抓取 80 多个站点，自动化抓取可能触及目标站点的使用条款或触发频率限制，建议控制抓取频率。
- **AI 产出质量取决于你自己配的模型**，与软件本身无关；调用会产生你自己的 API 费用。
- 我未下载安装，实际稳定性、导出格式兼容性和目录位置均未验证。
- 关注度数据口径提醒：同一时间 GitHub API 返回 816 Star，页面显示 700 Star，本笔记采用带时间戳的 API 数据。
