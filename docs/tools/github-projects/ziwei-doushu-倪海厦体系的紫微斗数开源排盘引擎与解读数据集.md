**v3.0 样本数据集**：**518,400 条**（年 60 × 月 12 × 日 30 × 时 12 × 性别 2），压缩后 5.5 GB（分 3 卷）、解压后 33.1 GB，覆盖 1924–1983。

**两处必须记住的口径（README 反复强调，最容易被看错）：**

- **`hour` 是"时辰序号 0–11"，不是 0–23 点钟**（子 = 0 …… 亥 = 11）；文件名里的 `hHH` 也是序号（`h11` 是亥时，不是上午 11 点）。
- **晚子时 / 早子时换日**：23:00–23:59 按次日排盘、取 0；00:00–00:59 按当日排盘、同样取 0。
- **v3.0 有约 2,520 条日期并不存在的样本**（生成时每月都取 1–30 日，于是有 2 月 30 日、非闰年 2 月 29 日），占 **0.49%**；旧引擎会把它们顺延成 3 月 1–2 日排盘，**内容与对应日期样本重复**。README 给了过滤条件，并说明**引擎自 2026-10-03 起会直接拒绝不存在的日期**，下一版数据集不会再有。
- **数据集与引擎可能不一致**：引擎会持续更新，v4.0 是按 2026-10-15 版断语库（内容版本 `ca268829f7a9`）生成的；README 自己举了个例子——**2026-10-20 星曜亮度默认从"现代修正 v2"改成《斗数全书》，而 v4.0 数据集是按旧默认生成的**。

## 排盘引擎能做到什么

`lib/ziwei/` 是排盘内核。README 对照常见排盘库列出的差异点：

- **真太阳时校正**：按出生地经度算时差 + 均时差（`cities.ts` 含中国城市经纬度；2026-10-27 起支持海外出生地，传 `utcOffsetMinutes`，国内不传时结果逐位不变）。
- **中国夏令时**：1986–1991 年的区间自动判定 —— **只判定、从不自动扣除**；钟表读数由用户确认后用 `clock-adjust.ts` 换算（README 曾把"自动扣除"写错，2026-10-27 已更正）。
- **闰月四种口径**（归前月 / 归后月 / 按日切分 / 按本月，可配置，不写死一派）；**闰月归属参数写错时当场报错**，不再静默按"归本月"排盘。
- **晚子时换日**：填了出生地时改按**真太阳时**判断（与时辰同一口径）。
- **星曜亮度 7 档**（庙 / 旺 / 得 / 利 / 平 / 不 / 陷）+ **流派可切换**；四化与飞星（生年 / 大限 / 流年四化、飞星自化）；十二神煞（本命按生年支起、流年层按流年支起）。
- **格局判定**：**1100+ 行规则库**（`patterns.ts`，紫府同宫、日月并明、七杀朝斗等）。

**回归测试与 CI**：`npm test` 一条命令跑 24 个回归脚本（排盘完整性、夏令时、立春边界、红鸾天喜、样本时辰一致性、日期合法性、同宫双四化等），每次 push / PR 在 GitHub Actions 上跑。README 说 2026-09 更新前**仓库里一个测试都没有**，是这一轮才补上的（`npm run typecheck` 另做全量类型检查）。

## 使用前需要注意

- **许可分层是最大的坑（事实）**：同一仓库里四段内容四种协议，**"能商用"与"不许商用"并存**。用数据集做微调 / 商业产品时只能取 CC BY 4.0 的部分并保留署名；**倪师原话属 CC BY-NC-SA 4.0，不许商用**；数据集里引用的倪师原话也不在数据授权内。
- **它不是一个能自托管的成品（事实）**：**断语库、AI prompt、后端 API、用户系统、部署配置都不在仓库里**；`db-analysis.ts` 只是占位。**你要的不是"克隆就跑起来"，而是"拿引擎和数据集自己搭"**。
- **Demo 与线上差距很大（README 自报）**：界面行数对照表已列出；**"Demo 能画盘，但给不出线上那套解读"**——线上那套的核心（上万行断语）恰好是闭源部分。
- **数据集很大、取用要有准备（事实）**：v4.0 解压后 **56.6 GB**（压缩 161 MB，逐年份分 77 个文件可只下需要的年份）；解压 zstd 需带 **`--long=27`**（长窗口），Windows 用官方 `zstd.exe`；有 `SHA256SUMS.txt` 可校验。**克隆仓库本体则是常规体量**（`package-lock.json` 约 116 KB、README 约 29 KB）。
- **`hour` 口径与"不存在日期"是数据使用的两个已知雷（事实）**：前者是「序号 0–11 不是钟点」，后者是 v3.0 有 0.49% 的日期样本无效（已给过滤条件）。
