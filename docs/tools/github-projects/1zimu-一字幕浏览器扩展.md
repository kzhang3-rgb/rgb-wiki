## 核心结论

`1zimu-com/1zimu` 对应的产品是**"一字幕"浏览器扩展**，定位是**看外文影视/视频学外语的辅助工具**：支持在线外文视频、电影、美剧、音频、内嵌字幕视频与可外挂字幕的**字幕列表播放**。

最需要先看清的一点，README 开篇就写明了：

> "**一字幕浏览器扩展不是开源软件，本仓库无源码。**"
> "此仓库仅作为本扩展的 Releases 版本发布，以及在 GitHub Issues 中跟踪 bug 信息、用户反馈。"

也就是说——**仓库挂在 GitHub，但它是一个闭源软件的"发行页 + 反馈区"**，不是一个可读、可构建、可审计的开源项目。这也是它 GitHub `language` 显示为 HTML 的原因（仓库里只有说明页，没有扩展源码）。
