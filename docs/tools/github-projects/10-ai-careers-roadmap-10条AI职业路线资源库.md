## 核心结论

一份 **awesome-list 式的职业路线资源库**：把 10 条 AI 与技术岗位路线各自整理成一个 `careers/NN-*.md` 页面，每页给出"从这里开始"的有序路径与社区入口。

十条路线分别是：AI 工程师、机器学习工程师、机器人工程师、LLMOps 工程师、AI 顾问、网络安全工程师、云工程师、AI 产品经理、数据工程师、AI 研究科学家。

它相对同类"资源大杂烩"做得好的三点：

- **一页一条路线，且强调"选一条，别十条都学"**——README 明确写着"Don't try to learn all ten"，并把"Go deep, then wide"（先深后广）作为使用原则；
- **每页开头是短小的有序路径**，而不是一堆链接（README 称其为 `🎯 Start here` 区块）；
- **标注了免费程度**：`🆓` 表示完全免费，`🆓⭐` 表示"可免费学/旁听，证书可选且可能收费"——**没有含糊地把"免费旁听"当成"完全免费"**。

- `careers/01-ai-engineer.md` 至 `careers/10-ai-research-scientist.md`：十条路线各一页；

## 使用前需要注意

- **薪酬数字是营销性质，不能当数据用**：标题里的"$135K–$1M+"来自原始 X 文章，**仓库没有给出统计口径、样本、地区或时间范围**。README 自己也写明"Compensation varies wildly by location, seniority, and company. **Treat the numbers as motivation, not a promise**"。按本站对金融/收益类内容的处理原则，**这类数字应视为宣传语而非事实**。
- **美国的薪酬与就业背景**：这些区间是美国市场的口径，**对中国大陆或其他地区的读者不具备直接参考性**，岗位名称与招聘习惯也不同。这是判断，不是仓库的说明。
- **创建即停更，链接会烂掉**：仓库创建与最后推送是同一天（2026-07-14），说明它是一次成型后没有维护。这类纯外链清单**最容易随时间失效**，而仓库里看不到任何死链检查机制（不像有些 awesome list 会跑 CI 验证链接）。**引用前逐条确认仍然可访问**。
- **33 Star / 8 Fork 的小项目，无第三方验证**：资源质量、路径是否真的"够入门"都未经审核；它绑定一篇 X 长文（作者 @exploraX_），**内容有引流成分**，README 里也没有说明资源是如何筛选的。
- **它是"配套资源库"而非独立作品**：脱离原文章单独看，部分路线页的取舍逻辑会缺失。
- **许可证极宽松**：CC0-1.0 意味着可以任意搬运、改写甚至商用而无需署名——**这对使用方是好事，但也意味着它可能被别人重新包装后当作付费课程出售**。
- **我只读了 README 与元数据，没有打开任何一条资源链接**：所有课程与资源是否免费、是否仍然有效，均未验证。
