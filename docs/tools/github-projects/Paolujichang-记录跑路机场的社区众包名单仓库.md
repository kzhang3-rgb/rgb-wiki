## 投稿与判定口径（README 自述）

- **投稿优先走 Issue**（便于其他受影响用户与被点名方参与），也可投稿至 Telegram 机器人；README 提醒注意甄别 Issue 与回复中的**推广 / 投机 / 引流**内容。
- **72 小时规则**：问题出现未超 72 小时、此前一段时间较稳定的，**建议先别提交**；先联系机场官方客服、看官方公告、等一段时间。对"未经审视而提交"、且最终属临时性问题的 Issue，管理员保留删除权。
- **六档状态分级**：🟡 暂时波动 / 🟠 持续异常 / 🔴 跑路预警 / 🟢 问题解决 / ⚫ 已确认跑路 / 🌪️ 不可抗力导致的服务终止。
- **立场**：明确"不是给某一家判死刑"、"一次波动不等于跑路、一次恢复也不代表风险永远消失"，并欢迎机场方出面解释与补充。
