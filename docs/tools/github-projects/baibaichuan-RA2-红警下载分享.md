## 内容结构

README 的章节大致如下：

- **各个网盘下载链接**：123 盘、天翼云盘、阿里云盘（内容不全）、谷歌 Google Drive（解压密码 `baichuan`）；**百度网盘已放弃**（作者称账号被"玩废"）。
- **假如分享全部失效怎么办**：建议买正版（Steam 已上架红警 2）、用对战平台目录自带的游戏文件夹当单机版、或找口碑好的 up 主 / QQ 群资源。
- **红警联机**：红警战网（`ra2ol.com`）、兰博（`ramboplay.com`）。
- **补丁 `ddraw.dll`**：指向开源项目 **`cnc-ddraw`（CnCNet）的 releases**；作者分享的补丁包版本为 1.3.4。**所有系统（XP / 7 / 8 / 10 / 11）都要打补丁**，用新版补丁后**禁止再设兼容模式**（会崩）。
- **红警常见问题**：黑屏 / 不显示菜单 / 卡顿（打补丁）、闪退 / 画面倾斜（高 DPI 设置）、花屏紫边（去掉兼容模式）、"无法初始化"（路径不能有中文、需完整解压）、FATAL String Manager（打补丁 + 运行 `RegSetup.exe` / `RegSetMD.exe`）、改分辨率（`ra2.ini` / `ra2md.ini` 的 `[video]`）、窗口化（`Alt+回车`，旧版 `-win` 参数与补丁冲突）。
- **更新日志**（倒序）与一句"彩蛋"说明：为通过 Gitee 开源审核，作者补了一份**能跑的 `红警有多少颗树？.py`** 脚本"注水"。
