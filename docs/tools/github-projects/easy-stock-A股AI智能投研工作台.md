# easy-stock：A 股 AI 智能投研工作台

> 一句话定位（README 自述）：**"A 股 AI 智能投研工作台"**——把**行情与题材 → 个股研究 → 持仓巡检 → AI 持仓优化**放进同一个**本地优先（Local First）**的研究流程（原话："把盘中观察、盘后复盘和长期认知，沉淀为一套持续进化的研究系统"）。技术栈是 **Go 后端 + React/TypeScript 前端 + Electron 桌面宿主**，AI 侧提供 **Hermes / Codex 双运行时**，可选 **OpenAI、DeepSeek、通义千问、Moonshot、Anthropic** 以及兼容接口的自定义服务；数据侧聚合 **开盘啦、东方财富、新浪、财联社**，并可从**雪球 / 淘股吧**作者主页自动同步复盘文章（微信公众号仅支持粘贴具体文章链接导入）。最值得记的是三点：① 它先把**A 股领域模型**（题材、梯队、连板、情绪、量价、相对强度）算成"可计算的领域模型"再交给 AI 解释，而不是"在传统行情终端旁边多放一个聊天框"；② 强调**证据可追溯**（保留评分维度、题材来源、原文地址、更新时间、延迟与降级状态）；③ **许可证是 PolyForm Noncommercial 1.0.0——源码可用（source-available）、非商业**，README 明写"不属于 OSI 定义下允许商业使用的开源软件"。

## 核心结论

1. **定位**（README 自述）：不是"行情终端 + 聊天框"，而是**AI 原生工作台**——把感知市场、理解结构、执行任务、形成记忆、验证结论做成一条链路；作者的口号是 **"Local first · Evidence based · Human in control"**，并明确"目标不是替你做决定"。
2. **完整功能面**（README 自述）：**AI 总控台、个股分级研究、持仓 AI 巡检、AI 持仓优化、监控中心、短线连板、趋势题材雷达、行情总览、大 V 自动复盘、AI 对话、游资心法库**；README 用"发现机会 → 研究证据 → 检查组合 → 持续监控"把界面串起来。
3. **AI 侧是双运行时**（README 自述）：统一 Agent 服务可按配置选择 **Hermes 或 Codex**，两者**共享模型连接、思考强度、Skills 与 MCP 设置**，分别管理原生会话；**Codex 需要支持 Responses 的模型连接**，并使用原生 App Server。
4. **本地优先与可追溯**（README 自述）：文章、摘要、情绪历史、分析记录、模型会话与研究缓存保存在本机（SQLite）；研究报告"把来源陈述、第三方观点与研究推断分开"，并保留引用与证据时点；巡检与优化按阶段保存检查点，支持一致条件下续跑。
5. **发布与分发**（README 事实）：安装包与自动更新**统一由 GitHub Releases 分发**，源码另有 **Gitee 镜像**（<https://gitee.com/zhoujundi/easy-stock>）；README 提示"从 v1.5.2 及更早版本升级"需覆盖安装一次，**macOS 更新仍需手动下载 DMG，Windows 可在应用内更新**。
6. **许可证**（`LICENSE` 与 README 事实）：项目原创的后端、前端、桌面端和文档采用 **PolyForm Noncommercial License 1.0.0**，`LICENSE` 顶部还有自定义前言"**easy-stock Non-Commercial License**"（要求保留 `Required Notice`，并写明商业使用需另行书面授权）；**第三方依赖、数据源与随包材料不受本许可重新授权**。

**个人判断（未验证）**：这个仓库的亮点在"**把 A 股语境做进数据模型**"与"**本地优先 + 证据留痕**"两条路线；但它同时是**重度依赖第三方行情/资讯数据源**（开盘啦、东财、新浪、财联社、雪球、淘股吧）的桌面应用，**数据可用性、抓取合规性与登录会话稳定性都不可由本仓库保证**，这部分只能实测。**非商业许可**则直接决定了它不能进企业生产环境或任何收费链路。

## 能力结构

### 1. 主界面（README 截图区，共 10 张）

AI 总控台（市场信号、今日任务、持仓健康）· 个股分析（证据、评分、研究结论）· 持仓 AI 巡检（四维评分、逐股依据）· AI 持仓优化（原组合 vs 建议组合）· 监控中心（自选与监控规则）· 短线连板（情绪曲线、涨停梯队、昨日反馈）· 趋势题材（主线热度、题材梯队、K 线）· 行情总览（新闻快讯、题材信号、资金榜单）· 大 V 自动复盘（作者文章同步与归档）· AI 对话（模型对话与研究任务入口）。README 提示**图中行情和评分仅用于展示界面**。

### 2. 八项功能说明（README 展开区）

- **大 V 自动复盘**：自动同步**雪球 / 淘股吧**作者主页，微信公众号仅支持粘贴链接导入；可一键生成"**今日大 V 观点共识**"；**定时复盘**取深交所交易日历，默认在交易日前一个自然日 **22:00（北京时间）**执行，周末节假日按日历跳过，可勾选**飞书 / 钉钉**接收完整 Markdown（**不含原文及具体证据**，长报告自动分段）——**需保持应用运行、电脑唤醒并提前同步文章**。
- **超短连板分析**：涨停池、连板梯队、昨日反馈、晋级率、情绪历史放同一视图，结合历史快照识别情绪周期。
- **趋势题材雷达**：聚合题材排名、涨跌强度、资金流、上涨宽度与持续天数；新增**题材指数日 K / 周 K / 月 K**，并区分**数据源指数与等权参考指数**（README 明确提醒"避免把参考曲线误当成官方指数"）。
- **行情总览**：核心指数、新闻快讯、行业趋势强度、行业资金、题材概念、个股资金、龙虎榜、公告雷达、机构观点与产业透视统一入口；**每个页面保留数据来源与抓取时间**，可把当前上下文交给 AI 解读。
- **个股分级研究**：三种用途（观察 / 准备新开仓 / 已有持仓）× 三个周期（超短 / 波段 / 中期）；研究方式分**量化速览**（不调模型）、**AI 快速研判**、**AI 标准研判**、**AI 深度研究**四档。
- **持仓 AI 巡检**：多份持仓方案，可设交易风格（激进 / 均衡 / 稳重）、持有周期、最多 10 只股票、总资产（默认 50 万元）；**优先复用 24 小时内有效的个股 AI 报告**；组合综合评分按固定权重由程序复算校验——**持仓逻辑质量 35% / 组合结构合理性 25% / 风险管理质量 25% / 策略匹配度 15%**；支持**每 3 天 / 每周 / 每月的定时巡检**并推送飞书 / 钉钉。
- **AI 持仓优化**：巡检报告里点"AI 优化持仓"，依次做候选筛选、个股研究、投资比较、程序配仓、独立复评；**约束**——股票总仓位与现金不变、**累计替换不超过优化链初始股票仓位的 70%**、最多新增 2 只、目标最多 10 只；原持仓与建议持仓**同次独立复评**；**不会自动下单或修改实际持仓**，评分"不代表收益率或胜率"。
- **游资心法与 AI Copilot**：经验材料（人物资料等）沉淀为可研读知识库；AI 会话经本机统一 Agent 服务，可选 Hermes 或 Codex 运行时。

### 3. AI 原生架构（README 分层表）

工作台层（React + TypeScript）→ **Go 本地 API**（HTTP 查询与后台任务轮询、WebSocket 行情与 AI 事件、本机鉴权与请求日志）→ **领域服务与任务编排**（题材融合、梯队与情绪计算、拐点评估、持仓报告复用与组合评分、观点共识、次日验证与定时同步）→ **数据与本地证据**（多源适配与回退、统一行情模型、题材归因、**带来源和时间的版本化快照**；SQLite 保存检查点）→ **统一 Agent 服务**（Hermes / Codex、Token 用量统计）→ **Electron 桌面宿主**（装配 Go / Hermes / Codex / Python；分配本机端口与启动 Token；**雪球与淘股吧 Browser Bridge、agent-browser 回退**；日志、更新与安装前备份）。

### 4. 每日研究闭环（README 表）

盘中发现 → 个股研判 → 持仓巡检 → 持仓优化 → 收盘复盘 → 信息收集 → AI 提炼 → 长期积累；README 用"感知 / 理解 / 行动 / 记忆 / 验证"五列描述这套"**研究飞轮**"。
