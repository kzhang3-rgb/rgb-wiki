# GitHub 项目收藏

[返回工具使用](../README.md) · [返回首页](../../../README.md)

收集值得长期跟踪的开源项目。收藏标准不是"看起来不错"，而是能说清它解决什么问题、以后什么情况下会再看。每个项目单独一篇笔记，这里只保留索引。

## 收录标准

- 记录真实用途、适用场景和限制，不复述项目自述当作评价。
- 明确标注核实范围：只读文档、看过源码、还是实际使用过。
- 关注度和维护状态按核验日期记录，并说明会随时间变化。
