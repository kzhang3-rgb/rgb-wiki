## 核心结论

一份逐条标注成本与收益的生活指南，目前 498 条建议，覆盖长寿防病、急救、省钱理财、法律红线、失业与工伤、恋爱婚育、育儿、创业合规、出国与技能。

它和其他"人生建议"清单最本质的区别是**每条都写明四项**：花掉什么（钱 / 时间 / 精力 / 毅力）、换回什么、证据有多硬（A/B/C 三级）、以及原始出处（期刊论文附 DOI 或 PubMed，或 WHO、CDC、国家统计局等官方文件）。作者声明不引二手转述。

仓库里同时是一个用于在线阅读和检索的小站：正文在 `book/` 目录，配套按关键词、章节、证据等级和成本维度筛选的[在线检索页](https://eternity4719.github.io/HowToLiveBetter/)。

## 条目长什么样

README 给出的示例让我能判断它的信息密度——每条建议包含成本、说人话、收益、证据等级、来源和备注：

```text
### 5. 把家里的食盐换成低钠盐（钾盐）
- 成本：每袋贵几元
- 说人话：两万人的随机试验里，换低钠盐的人五年内死亡概率低约 12%，中风低约 14%。
- 收益：脑卒中降 14%，心血管事件降 13%，总死亡率降 12%
- 证据等级：A
- 来源：Neal B, et al. (2021). NEJM. https://doi.org/10.1056/NEJMoa2105675
- 备注：争议。肾功能不全、正在吃保钾利尿剂的人不要用。另列出一项结论相反但证据等级更低的生态学研究。
```

几个设计细节值得借鉴：

- **"说人话"独立成行**：把风险比、置信区间翻成日常说法，且声明只用原文已有事实、不引入新数字。不想看统计术语的人只读这一行就能决策。
- **争议条目标"争议"并列出反方证据**，而不是只留一条顺手的结论。
- **节标题说的是要防住的结果**（"不要早死""不要浪费时间"），条目标题才是动作且一律动词开头。README 专门解释了这一点，避免读者把节标题当成禁令。

## 证据分级与性价比档（两个正交维度）

| 等级 | 含义 | 占比 |
| --- | --- | --- |
| A | 有可量化证据，来自荟萃分析、大型队列或 RCT，能给出具体数字 | 323 条 |
| B | 有研究支撑但难以量化，或来自小样本 / 单一研究 | 126 条 |
| C | 作者经验或普遍共识，没有直接文献 | 49 条 |

另有 45 条标注了争议、39 处标注 TODO 待核实。全书按性价比分成极高 88 条、高 248 条、一般 162 条。

**这里有一个我认为最有价值的设计**：作者明确区分了两件事——证据等级回答"数字可不可信"，性价比档回答"值不值得做"，两者**正交**。并主动声明性价比档"本质上是 C 级、是作者判断而不是证据"。所以会出现 A 级但性价比一般（带状疱疹疫苗效力 97.2% 的三期 RCT，但两针三四千元且很少致命）、C 级但性价比极高（出境前把行程发给家人）这样的组合，作者也没藏着。

收益还按"算在谁头上"分四档：自己 → 配偶与直系亲属 → 朋友同事及其他亲属 → 陌生人，各档不合并计算；写到陌生人一档时好处与风险一起写（急救那一节即按此读）。不同口径（寿命 / 钱 / 时间精力 / 人身自由）之间声明不做换算和比较。

## 阅读与检索方式

- **按条件筛**：检索页支持关键词、章节、证据等级，加上"花不花钱、花多少时间、要不要毅力"三个成本维度组合筛选。
- **数据源是正文**：检索页直接读 `book/` 下的 markdown，改正文即改检索页，没有额外的数据库要同步。
- **配套**：40 条术语表（总死亡率、HR、RR、95% CI、荟萃分析等）、核实记录、若干长文（结婚划不划算、家庭应急装备清单、做平台要办哪些证等）。

仓库里还有一份 `CLAUDE.md` 规则文件，说明这份指南是用 AI 协作维护的——规则外置、正文可核对，这个做法和指南本身的"要留证据"是一致的。

## 使用前需要注意

- **不是医疗、法律或投资建议**：虽然引用了原始文献，但条目是作者对文献的解读与取舍，涉及用药、疾病、法律后果时仍应咨询专业人士。
- **适用地域是中国大陆**：条款、补贴、证件、流程均按中国大陆的官方文件与法规写成，换国家或地区不适用。
- **仍有多处未核实**：39 处标注 TODO 待核实、45 条标注争议，作者自己也没标为完成品。
- **许可证有一处口径冲突**：仓库内 `LICENSE` 是 Unlicense（公有领域），但 GitHub API 元数据标为 CC-BY-4.0。以仓库内的 `LICENSE` 为准，转载前建议自己再确认一次。
- **关注度数据不可信**：API 与页面差近 160 倍，别用它判断这个项目的影响力。
- **我只读了 README、目录和许可证**，没有逐条核对引用文献是否被正确解读，内容准确性未经验证。这类"每条都带来源"的形式容易让人降低警惕，但引用存在不代表结论成立，遇到影响健康的条目建议自己点开原文。
