一个从 2017 年持续写到现在的中英双语终身学习指南，作者是韩先凯（笔名"离谱"）。起点是《离谱的英语学习指南》，现在已扩展到 AI 学习、真实项目、创业、人生复盘与恢复，英语退为其中一条基础路径。

## 书稿结构

主线是阅读指南与序章，之后分五部，最后是后记：

| 部分 | 核心问题 |
| --- | --- |
| 阅读指南与序章 | 我从哪里进入，又为什么要重新开始 |
| 第一部：打开输入 | 怎样建立英语和世界之间的通道，并把能力带进面试与远程协作 |
| 第二部：把自己放回生活 | 能力、事业、关系、失败、选择与恢复怎样互相影响 |
| 第三部：借工具放大能力 | 怎样使用 AI，而不把判断力和注意力一起外包 |
| 第四部：实践与恢复 | 学习如何回到身体、家庭与日常 |
| 第五部：行动与长期改变 | 怎样完成九十天，也让方法在此后继续接受检验 |

第一部是具体的英语能力篇（CEFR 自测、词汇、语法、听力、阅读、口语、写作、求职英语），后几部转向方法与真实生活。

## 它反复练习的一件事

全书围绕一个循环：

```text
发现问题 → 主动学习 → 与 AI 协作 → 完成真实任务 → 保存证据 → 复盘迁移
```

配套了一批可复制的工作纸：学习状态表、生活进阶工作表、九十日行动总表、每周复盘，以及语法、阅读、词汇、听力、口语、写作六类证据卡，另有英语能力诊断与作品简报。另有术语索引（按"定义 → 证据 → 下一步"组织）和工具箱总览作为入口。

## 值得借鉴的两处写法

**1. 区分三类信息的可信度。** 作者在开头明确把内容分成三类：

- **研究结论**：提供来源，并说明证据能覆盖到哪里。
- **个人经验**：保留故事的温度，不把一条人生路径冒充成普遍规律。
- **待验证假设**：允许想象进入讨论，但必须交给下一轮行动检验。

**2. 主动写下降级声明。** README 里公开声明了身份与商业关系（作者写明自己是中国词元云计算有限公司董事长），列出关联项目及非赞助关系，并明确标注第三方推荐入口（AI 中转站、TG 频道）不等于本书或作者的安全、质量与合规背书。个人经历部分也声明不构成医疗、法律、投资或创业建议。

这种"把利益关系和能力边界写在明处"的做法，比多数同类内容可靠。

## 仓库工程部分

书稿之外，仓库里有完整的出版流水线，可参考其做法：

```text
docs/                书稿正文（含 docs/en/ 英文版）
book-assets/fonts/   印刷字体
legacy/              旧版内容归档
scripts/             构建与 PDF 生成脚本
tests/               测试
```

配套 `package.json`、markdownlint 配置、`playwright.config.mjs`，以及 `requirements-fonts.txt`、`requirements-pdf.txt`（构建双语印刷版 PDF）。提交记录里能看到链接失效巡检、字体与 PDF 校验等自动化维护动作。

## 使用前需要注意

- **这是个人视角的长文书稿，不是工具或标准教材。** 作者的自我声明说明白了：个人经验不等于普遍规律，全部内容属于待验证的方法框架。
- **许可要分开看**：代码和文字内容各有许可证文件，引用或转载正文前先确认 `LICENSE-CONTENT.md` 的要求。
- **内容持续变动**：书还在写，2026-09 还在调整章节与出版流程，引用具体段落时最好记下核验日期。
- **第三方链接不是背书**：README 自带的推荐入口同样如此，使用前自行核对条款与风险。
- 我只读了 README 和目录结构，没有通读全书，对内容质量不作评价。
