## 核心结论

1. **明确定位**（README 自述）：用 AI 把《史记》转成**可交互的知识图谱**；核心成果为 **14,065 个实体、126,441 次标注（18 类名词 + 4 类动词）**、**3,198 个历史事件**（98.7% 标公元纪年）、**7,637 条事件关系**（9 类）、**130 条交互式时间线**（"史记地铁图"）。

## 能力结构

### 1. 核心数据与规模（README）

### 2. 九步管线（README）

`01 校勘 → 02 结构分析 → 03 实体构建 → [04 事件 / 05 关系 / 06 本体 并行] → 07 逻辑推理 → 08 SKU 构造 → 09 应用构造`；每步对应一份 SKILL（`skills/SKILL_01_古籍校勘.md` … `skills/SKILL_09_应用构造.md`），总览在 `skills/SKILL_00_管线总览.md`，索引在 `skills/INDEX.md`。

### 3. 阅读器与可视化（README）

- **22 类实体语法高亮**（可开关，偏好持久化）；**知识索引跳转**（14,065 个词条）；**Purple Numbers 段落编号**（每段可精确引用）。
- **"史记地铁图"**：130 条线 × 3,197 站点，支持缩放 / 拖拽 / 搜索 / 时间线。
- **Wiki + Butler agent**：butler 按轮次维护（新建 stub、深化精品页、引文核验等），每 23 轮批量提交；三层反思（W5 流程 / W9 图式 / W11 类型审计），见 `wiki/doc/butler-reflections.md`。
