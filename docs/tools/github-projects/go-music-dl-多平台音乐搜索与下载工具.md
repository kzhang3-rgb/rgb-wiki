# go-music-dl：多平台音乐搜索与下载工具

> 记录这个 Go 写的音乐搜索/下载工具的实际形态——**同一套后端跑 Web / TUI / 桌面端 / Android / iOS，再用 Docker 一键自托管**；覆盖网易云、QQ、酷狗、汽水、Bilibili 等 12 个平台，支持 FLAC 无损、Cookie 与扫码登录、本地音乐管理与 WebDAV 同步。第一句先记清三件事：**AGPL-3.0（强传染）**；**含"音频解密 / 会员整曲签名"等绕过付费获取整曲的能力，版权与平台条款风险显著**；活跃度真实（最近提交 2026-10-19）。

- 状态：草稿
- 最近核验：2026-11-03（阅读 README（GitHub 渲染版与 jsDelivr 镜像一致）、GitHub API 元数据、默认分支 `main` 的 commits 接口与最新 Release；**未安装、未运行、未配置 Cookie、未审计源码**）
- 适用范围：多端——Web（自托管 / Docker）、TUI、桌面端（Windows/Linux/macOS，含 Rust 与纯 Go 两版）、Android APK、iOS（需自行签名）

## 核心结论

它解决的是"**把多个音乐平台的搜索与下载收进一个自托管服务**"这个问题。形态很特别：**一套 Go 后端 + 多套前端**，同一份能力可以从浏览器、终端、桌面窗口或手机 App 使用，也能用 Docker 挂在自己服务器上。

三点要先看清：

**① 它是"聚合器"，不是"音乐源"。** 所有内容都来自第三方平台的接口，平台改版或风控收紧，对应渠道就会失效；README 也承认某些接口"结果不稳定"（表中用 `⚠️` 标注，如千千、Jamendo 的歌单搜索）。**能不能用、能用多久，取决于上游平台。**

**② 它明确包含"绕过付费"的能力，这是与本笔记里其它项目最大不同的地方。** README 写明：汽水音乐"音频解密"、会员整曲可通过"**Cookie + 内置本机签名器**"下载（装过官方客户端即可用，也可配远程签名服务，都没有时回退试听片段）；Apple Music"下载仅 preview，完整需 `gamdl` 解密"。**这些行为涉及绕过平台付费/加密机制，版权与平台服务条款风险由使用者自担。** 本笔记只作信息记录，不构成使用建议，也不对合规性作定性。

**③ 许可证是 AGPL-3.0，传染性最强的一档。** 如果你打算改造后对外提供网络服务，AGPL 要求你把修改后的源码一并开源。自用没问题，**对外提供服务前务必读一遍 AGPL 的条款**。

## 它能做什么

**多端形态（同一后端）**

- **Web**：默认 `http://localhost:8080`，支持挂载到反向代理二级目录（`--base-path`）；搜索、试听、下载、歌单浏览**无需登录**，只有改设置 / 管理 Cookie 才要管理员账号（首次启动日志打印一次性 `Web setup token`）。
- **TUI**：`./music-dl -k "关键词"`，键位含全选、换源、批量下载、每日推荐。
- **桌面端**：`music-dl-desktop-rust` 或纯 Go 版，自动启动内置服务（README 称用少见端口避免冲突）。
- **移动端**：Android APK（Gio 打包，**已内置 ffmpeg/ffprobe**）、iOS IPA（发布的是未签名包，需自行重签）。
- **Docker**：一条 `docker compose up -d` 起服务，数据持久化到 `./data`。

**搜索与下载**

- 单曲 / 歌单 / 专辑三类搜索，支持直接粘贴**歌曲 / 歌单 / 专辑分享链接**自动识别来源。
- **FLAC 无损**：网易云、QQ 音乐、Bilibili（酷狗为"普通歌曲 FLAC"）。
- 试听、歌词、封面下载；歌词支持网易云/QQ/酷狗的**原文 / 译文 / 罗马音逐字 LRC**。
- **换源**：按歌名/歌手相似度 + 时长差异 + 可播放探测，在其它平台找更接近的版本（会跳过汽水与 5sing）。
- 下载设置：流式（支持 `Range` 断点）、可选内嵌封面/歌词（依赖 `ffmpeg`，缺失则自动跳过）、可**同步到 WebDAV**。
- 搜索过滤：可屏蔽 Live / Remix / Demo 等版本与 60 秒以下试听，并统一简繁体与零宽字符。

**平台覆盖（README 支持平台表，12 家）**

网易云、QQ、酷狗、酷我、咪咕、千千、汽水、5sing、Jamendo、JOOX、Bilibili、Apple Music。其中：

- 支持**扫码登录**：网易云、QQ、酷狗、Bilibili。
- **汽水音乐扫码未调通**（README 称其新版依赖动态 `a_bogus`/`msToken` 风控签名），需手动配 Cookie。
- **Apple Music 下载仅 preview**，完整需 `gamdl` 解密。

**本地音乐**

- 默认读取 `data/downloads`（Android 建议设为 `/sdcard/Music`）；支持 `mp3`/`flac`/`m4a`/`ogg`/`wav`/`wma`/`aac`。
- 上传、批量收藏到自制歌单、读取内嵌封面与歌词；缺失时用 `ffprobe` 补全。
- 已升级为**一等搜索源 `local`**（默认不勾选），由内置 SQLite 索引表驱动，配合分页与扫描快照缓存，几千首也能较快命中。

## 使用前需要注意

**① 绕过付费/加密的能力 = 更高的版权与条款风险。** 汽水的"音频解密 + 会员整曲签名"、Apple Music 的 `gamdl` 解密，都属于获取本应付费内容的手段。**这部分风险由使用者自行判断与承担**；本笔记只作信息记录。

**② 需要把平台 Cookie 交给它。** 要读"我的歌单"、更高音质或受限资源，就得配置对应平台 Cookie（README 称 Cookie **仅存本地数据目录、不上传第三方**，但未说明是否加密），并提醒"请勿公开分享配置文件"。**要不要交出账号登录态，请自行权衡。**

**③ AGPL-3.0 的传染范围。** 若你修改后对外提供网络服务，需按 AGPL 开源修改后的源码。商业使用前请先确认条款。

**④ 平台接口会失效、且各渠道稳定性不一。** README 的兼容表本身用 `⚠️` 标注了不稳定的接口；上游风控（如汽水的签名机制）一变，对应渠道就可能不可用。别把它当成"一次配好永远能用"。

**⑤ 未安装、未运行、未审计。** 以上功能全部来自 README、API 元数据与 Release 信息的自述；我没有安装、没有跑起来、没有配置 Cookie、没有审计源码，也没有验证任何平台的实际可用性。

- 想研究"**多源聚合 + 换源 + 本地库索引**"这类聚合器的设计（相似度打分、时长校验、SQLite 索引、快照缓存）时。
