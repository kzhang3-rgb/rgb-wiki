一个体量很大的量化交易学习与代码合集，从 2022 年持续更新：内容分十几块，横跨股票基础、传统策略、机器学习 / 深度学习 / 强化学习、图网络、高频交易、因子挖掘、文本分析、大模型、数据获取、在线投研平台（聚宽 / 优矿），以及 C++ 部署。

## 免费与收费的边界

README 开头就写明"本代码仓秉承**收费和免费并行**的原则"，这是使用前最需要知道的一点：

- **免费**：代码仓库永久免费，另有公众号等免费渠道。
- **收费**：作者的"知识星球"社群。
- **关键的一条**：README 明确写着"本代码仓会持续更新，但**部分代码转为私有化维护仅在星球中可见**，对应功能会在仓库中标注"。

也就是说，仓库里的内容**不是完整的**——部分功能只有标记、代码在付费社群内。评估"能不能靠这个仓库学会某个方向"时要把这点算进去。README 里也大量标注了"视频教程见星球或公众号""详细指南 + 模型见星球"。

## 头部的效果声明需要打折看

README 的"新特性"表里有一些很醒目的结论：

- 2023.03：**强化学习多股票交易，年化收益 53%**
- 2025.08：**推理型股价预测大模型训练教程，预测准确率提升 20%，且可解析**

这些数字来自作者自述，**没有第三方复现，也没有给出回测区间、样本范围、交易成本与滑点假设**。量化领域的"年化 XX%"在缺少这些前提时基本无法判断含义。我的建议是：把这类标题当"这个方向有示例代码"的线索，而不是当可复现的业绩证据。

## 使用前需要注意

- **依赖陈旧**：`requirements.txt` 的最近一次提交是 2022-11-07，`egs_online_platform`、`egs_data` 等目录也停留在 2022 至 2023 年。这些示例的库版本与 API 大概率已经失效，直接运行预期会报错，更适合当思路参考。
- **README 图片可能失效**：正文里的配图用的是带 `x-expires` 签名的图床外链，属于临时地址，未来会变成无效图片。这也侧面说明：外链图片不适合作为长期记录方式（本 wiki 因此把图片放在仓库内并用相对路径引用）。
- **适用人群写得过宽**：README 开头称适合"机构"与"散户（有无编程基础均可）"。以这个仓库的组织方式（十几块并列的主题、示例分散、部分内容在付费侧），无编程基础的散户很难独立跑通。
- **需要自备数据源**：Wind 万得、聚宽、优矿等都是独立账号体系，部分为商业付费数据，仓库只是接入示例。
- **这不构成投资建议**：任何策略示例都不能直接用于实盘，且 A 股相关策略受交易规则约束。
- 我未安装运行，未验证任何示例代码与效果声明。
