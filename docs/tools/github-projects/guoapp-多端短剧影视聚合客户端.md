## 核心结论

**一句话定位（README 自述）**：Flutter 多端独立短剧 / 影视应用，原名「短剧库 APP」；**站源请求、解析、下载和播放均在设备上完成，不依赖自建服务**。

**① 它是什么。** 一个把多个"站源"（红果、韩小圈、鬼片、青空……）聚合进同一个客户端的短剧 / 影视 App，覆盖浏览、搜索、推荐、追剧与历史、下载、弹幕、画中画、局域网互联等一整套播放器功能。

**② 一个仓库、两个编译版本——这是最需要先理解的设定。** 用编译选项决定可用站源：

| 编译方式 | 应用名称 | 可用站源 |
| --- | --- | --- |
| 默认（不加参数） | **红果鉴** | 仅红果 |
| 加 `--all-sources` | **真果鉴** | 红果、韩小圈、鬼片、青空，以及黄豆、剧果、野果、帝果、黄果视频、黄果 AI、黄果旧版 |

**这是编译期选项，应用内不能切换**。默认可见的站源（红果、韩小圈、鬼片、青空）无需密码，其余默认隐藏、需在站源管理里用密码锁解锁。两版保留同一 Android / iOS 应用标识，**可覆盖升级但不能并排安装**（README 明写）。

**③ 站源是 Go 原生 provider，不是运行期加载的脚本。** README 的"站源开发约定"写明：站源是 `native/core/provider_*.go`，新增站源要同时改 `provider_huangguo.go`、`provider_media.go`、`app_categories.go`、`app_cover_metadata.go`、`app_runtime.go`，并在 `lib/models.dart` 登记 `SourceSite`。作者还专门提示 **Go 的 RE2 正则不支持 lookahead**，解析多线路播放列表不能用 `(?=...)` 分段。

**④ 播放与增强链路。** 播放器用 [media_kit](https://github.com/media-kit/media-kit) / libmpv，合并与导出用 FFmpegKit min-gpl（含 GPL 媒体组件，但 README 称 FFmpegKit 不参与正常播放或下载的转码）；"画质增强"只在 Windows 桌面端显示并运行。

**⑤ 局域网互联（已接入，待验证）。** 两台设备在同一局域网直连，同步追剧记录或接续播放，服务类型 `_zgj-link._tcp`（DNS-SD / mDNS），首次配对记录证书指纹、后续固定校验——**README 自己标注"待验证"**。

## 功能与平台

- **浏览 / 搜索**：分类栏独立一行、内容区左右滑动切类；支持默认 / 名称 / 自然季号 / 上线日期 / 热度 / 播放量排序与连载状态筛选；列表接近底部自动加载下一页。红果合并官网与名称索引，输入停顿 300 毫秒显示最多 10 条联想；最近 20 次搜索按用户保存。
- **追剧与历史**：按想看 / 在看 / 已看 / 有更新筛选，每用户独立保存，每 5 秒及退出播放时记录真实进度。
- **下载**：可选分集与画质，支持批量暂停 / 继续 / 重试 / 删除，以及"更新本剧"补新增或缺失分集。
- **手机播放手势**：上滑下一集、下滑上一集，长按 350 毫秒临时 3 倍速；Android 手机 / 平板接入画中画（Android TV、Windows、iOS 暂未接入）。
- **弹幕**：红果在线播放默认开启，可关闭 / 查看状态 / 失败重试；本地播放不加载弹幕。
- **代理设置**：管理员可设自动 / 直连 / 手动代理（HTTP、HTTPS、SOCKS5 / SOCKS5h）；代理地址默认遮蔽、不进备份；**代理不会关闭 TLS 校验**。
- **平台状态**：Android 8.0+ 三架构 APK；Windows 10/11 x64 完整 ZIP 解压后运行 `hongguojian.exe` / `zhenguojian.exe`；Android TV 待实机验收；iOS 待 Xcode 构建与真机验收（无签名 IPA）。
- **构建 / 发布**：GitHub Actions 在推送 `main`/`master`、`v*` 标签、PR 或手动运行时构建两版；Android 正式发布需在 Secrets 配置签名（`ANDROID_KEYSTORE_BASE64` 等），未配置则生成 debug 签名预览包。
