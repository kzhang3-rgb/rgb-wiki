# ChinaTextbook：把中小学到大学的 PDF 教材放进一个仓库

> 记录一个"内容即仓库"的巨型项目：84,000+ Star、约 43.5 GB，几乎全是教材 PDF 本体——它值得记的不是代码，而是体量、版权状态与"怎么取用"。

- 状态：草稿
- 最近核验：2026-11-05（阅读 README、目录树与 GitHub API 元数据，未 clone、未下载任何教材）
- 适用范围：需要 PDF 教材文件本身；仓库极大，取用方式需专门考虑

## 核心结论

`ChinaTextbook` 是一个**教材 PDF 内容仓库**，不是软件项目——仓库里几乎没有程序代码，**内容就是教材本体**。

README 交代了两件事：

1. **项目由来**：一是为了对抗"把教材加水印后拿去贩卖"的二次分发，二是方便**海外华人子女**了解国内教育内容。
2. **内容范围**：覆盖小学、初中、高中到大学；README 用分学段的链接（尤其数学）引导取用。

与它配套的是另一个仓库 **`ChinaTextbook-tools`**：因为仓库里的 PDF 常有**分卷拆分**，README 给出用 `mergePDFs-windows-amd64.exe` **把拆分文件合并回整册**的做法。README 另设"**重新下载**"一节，**推荐使用 [tchMaterial-parser](tchMaterial-parser-国家中小学智慧教育平台电子课本下载工具.md)** 从官方平台自行获取——也就是说，作者自己给出了"内容未必需要从本仓库拿"的替代路径。

## 取用要点

- **绝不整仓克隆**：约 43.5 GB。优先**浅克隆**（`git clone --depth 1`）或**只按需下载具体文件**（GitHub 网页 / raw 链接 / `svn export` 单目录），不要把整个仓库拖到本地。
- **默认分支是 `master`**：脚本或链接里写 `main` 会拿不到内容。
- **拆卷要先合并**：部分 PDF 是分卷存放的，需用配套工具 `ChinaTextbook-tools` 里的 `mergePDFs-windows-amd64.exe` 合并成整册。
- **可以改用官方来源**：README 自己推荐用 [tchMaterial-parser](tchMaterial-parser-国家中小学智慧教育平台电子课本下载工具.md) 从国家中小学智慧教育平台重新下载——**想要"干净、最新"的版本，走官方平台更稳**。

## 使用前需要注意

- **许可状态"缺失"是最大的问题**：仓库**没有 `LICENSE` 文件**，API 的 `license` 与 `language` 字段都为空。没有许可证 ≠ 可以随意使用——**默认是"保留所有权利"**。教材的版权归各出版社/著作权人所有，**本仓库只是文件的聚集地，并不改变教材本身的版权归属**。涉及再分发、商用、对外提供服务时，应自行确认授权，不要把"能在 GitHub 上访问到"当成"可以自由使用"。
- **体量 43.5 GB 且无 Release**：没有打包好的发行包，只能从仓库树里逐项取；对网络与存储都是压力，**注意取用方式（见上）**。
- **3 位贡献者维护 43.5 GB 内容**：维护力量与仓库体量极不匹配，**文件缺失、链接失效、版本陈旧**都可能出现，遇到问题要有备用来源。
- **它是"内容仓库"，不承担"来源核验"**：README 说明的动机与用途是作者自述；文件是否为最新版、是否与官方一致，**本仓库不提供版本校验**。
- **与 [tchMaterial-parser](tchMaterial-parser-国家中小学智慧教育平台电子课本下载工具.md) 的分工**：一个是"内容已经在仓库里"（本篇），一个是"工具帮你从官方拿"（那篇）。**从合规与时效看，工具路径通常更稳妥**；从省事看，本仓库能一次拿全。
- 我**未 clone、未下载任何教材、未合并任何 PDF**：以上均来自 README、目录树与元数据。
