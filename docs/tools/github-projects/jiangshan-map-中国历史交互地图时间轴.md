# jiangshan-map：中国历史交互地图时间轴

> 记录这个把 2,400 年中国史做成"可拖动时间轴 + 可点古城"的纯前端作品：18 个历史时期、164 张疆域快照、地名沿革卡与人物纪事；同时记下引用历史地理数据时该有的谨慎。

- 状态：草稿
- 最近核验：2026-11-03（阅读仓库英文版 README 与 GitHub API 元数据，并用默认分支 `main` 的 commits 接口复核活跃度；未打开在线 demo、未部署、未核对任何历史地理数据）
- 适用范围：纯前端静态站点，浏览器直接打开在线 demo 即可；也可用 Docker 自部署

## 核心结论

一个把**中国历史疆域做成可交互地图 + 时间轴**的纯前端作品，时间跨度从战国（403 BCE）到今天，含 **18 个历史时期、164 张疆域快照**。玩法是"拖时间轴看疆域涨落、点任意古城/关隘看它的 2,400 年沿革"。

四块主要功能：

| 功能 | 做什么 |
| --- | --- |
| **时间轴 scrub** | 多政权在同一画布并列（七雄 + 周/越/巴蜀/中山/义渠、三国诸侯、南北朝、五代十国、宋辽西夏大理金蒙古……）；每个疆域里程碑切换时会露出上一阶段的**虚线朱红"幽灵边界差分"**，一眼看出得失；时间轴同时显示在位帝王（庙号 + 姓名 + 在位区间）与年号；河道、古湖泊（云梦泽、罗布泊）、历代长城与大运河随时代联动变化 |
| **地名沿革卡（Trace Place）** | 点任意古城/关隘（或双击画布）打开卡片：顶部是双语城市题记，下方逐朝代列出名称与行政区划演变（战国郡、汉州、唐道、宋路、元明清省），带"帝都"徽记；每行下挂**发生在该地的具体事件**（咸阳的商鞅变法与秦统一、樊城的关羽水淹七军、长安的玄武门之变、临安的岳飞遇害……） |
| **人物纪事（点人溯事）** | 搜索任意帝王/将相/僧人/诗人，把其一生节点画成地图上的细线弧与方向刻度：秦始皇统一战争、张骞通西域、诸葛亮出山与北伐、玄奘西行、李白壮游、苏轼贬谪、王阳明知行合一——每按下一步，**时间轴、帝王、年号与疆域同步跟着人物脚步走** |
| **彩蛋：地图定位挑战** | 隐藏城市名，给出朝代线索让你在图上下针，按大圆距离打分，10 轮后按成绩给一个古代舆图官职头衔（如"太史令 · 舆图大家"） |

另外支持键盘快捷键（`/` 或 `Cmd/Ctrl+K` 搜索、`←/→` 进退、`Shift+←/→` 十年一跳、`Space` 自动播放）与**可分享深链接**：`?year=`、`?place=`、`?person=`、`?quiz=locate` 都能把"当前视图"编码进 URL，例如 `?year=1415&place=应天府` 直达明永乐十三年的应天府沿革卡。

## 使用前需要注意

**① 这是一份"作者整理的历史地理数据"，不是权威边界数据。** 疆域线、地名沿革、郡县对应关系都由作者整理/绘制，边界划分与地名归属在学术上常有争议（比如不同时期政权的实际控制范围、古地名与今地的对应）。**当作"帮助定位与理解的工具"没问题，但引用到正式场合前应回到专业史料核实。** 这条属于"论文自述 vs 我的判断"里的后者，特此标明。

**② 涉及时期与领土的历史表述，引用时注意语境。** 地图天然要画边界，且它按时期并列不同政权（含秋海棠图 → 雄鸡图的演变等）。本笔记只记录"它呈现了这些内容"这一事实，不对其中任何历史地理结论作判断。使用时请自行注意语境与适用场合。

**③ 仓库体积约 124 MB。** 164 张快照加演示图片都在仓库里，clone 会比较慢；在线 demo 则无需下载。

**④ GPL-3.0。** 若要二次分发或用于对外的网络服务，先确认传染义务。

**⑤ 未打开 demo、未核对数据。** 我没有打开在线站点、没有部署、没有逐条核对任何地名沿革或事件年份，功能描述全部来自 README 自述。
