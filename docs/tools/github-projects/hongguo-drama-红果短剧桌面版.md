# hongguo-drama：红果短剧桌面版

> 记录这个 Electron 短剧客户端的实际能力（三来源搜索、播放、下载、追剧合并、NAS 落库、扫码登录读 APP 记录），以及它的三个前提：**社区修改版、非官方客户端**；Windows EXE 未签名；README 宣称的 Mac 签名／公证与 `package.json` 的构建开关互相矛盾。

- 状态：草稿
- 最近核验：2026-11-03（阅读 README 全文、`package.json` 与 GitHub API 元数据，并用默认分支 `main` 的 commits 接口复核活跃度；未下载安装包、未运行、未登录任何账号）
- 适用范围：macOS 13+（M 系列 / Intel）与 Windows x64；Electron 桌面应用，内置 FFmpeg、无需另装 Node.js／Homebrew

## 核心结论

把"红果短剧"的**搜索、播放、下载、追剧与合并导出**收进一个桌面应用。作者自己的能力清单是"三来源搜索 + 播放 + 下载 + 追剧"，功能谱系从 3.x 一路长到 5.4，看得出是长期在用的个人工具。

**但它的第一句定位就得先看清**，README 第 33 行原文：

> 本项目是社区维护的开源修改版，**不是红果、西饭或河马的官方客户端，也未获平台官方背书**。不提供付费分集解锁；剧集、清晰度和可用范围取决于来源平台。

这句话决定了后面所有风险都归自己承担：它取的是来源平台的接口与页面，账号、版权与平台条款的边界都由使用者自己站。

## 它能做什么

按 README 的版本说明梳理，能力大致分四块：

**取内容与播放**

- 三来源搜索：输入剧名、红果分享链接或剧集 ID；搜索页支持"换一批"读取真实下一页。
- 在线播放带"自动（1080P 优先）"：先试 1080P，失败依次退 720P 与兼容片源，换档保留播放进度与暂停状态。
- 老电脑兼容模式（H.264 优先）：对已知 H.265 片源提前转码，减少"先黑屏再失败"。
- 画中画有"系统原生 / 应用自带"两种可选，默认自带小窗（显示剧名、记忆尺寸）。
- 5.4 新增**同局域网 DLNA 搜电视 + 单集投屏**。

**下载与整理**

- 下载队列、失败重试、整剧合并；合并有三种方式，快速与兼容合并**按每段原始分辨率拼接**（低清不会拖低高清）。
- 5.3 新增**下载到 NAS**：挂载共享目录后每部剧一个文件夹，视频、封面、简介、剧集与分集 NFO 同层保存；分集按 `剧名 S01E001.mp4` 命名。
- 下载管理里可直接打开保存目录；断电/改路径/同名冲突都有提示。

**追剧与记录**

- 观看记录按季号分组，5.0 起加入"疑似同剧（仅提示）"——同来源同剧名但季号写法不明确时只提示不归组。
- 4.3 起有独立**登录管理**：用手机红果 App 扫网页登录二维码，登录后可读取当前账号**最近 50 部 APP 观看记录**并按剧名搜索；登录态用系统安全存储加密。
- 4.1 起可随下载**导出弹幕、评论、剧评 JSON**（该功能源于贡献者 `jayeeliu` 的 PR #61，**仅支持红果来源**，评论/剧评只含官网公开可读部分）。

## 下载与安装

当前正式版 5.4 提供 Mac arm64 / x64 的 DMG（macOS 13+）、Windows x64 安装版 EXE、便携版 EXE 与便携 ZIP，发行页另附 `SHA256SUMS.txt` 供校验。**普通使用只需装这些可执行文件**——发行页里的 Mac 更新 ZIP、`latest*.yml`、`.blockmap` 是给更新程序用的，`source` 与 GitHub 自动生成的 Source code 是源码，不能直接运行。

从源码构建时的关键配置（`package.json`）：

- 打包入口：`main.js`、`preload.js`、`dist-react/**/*`、`src/native/**/*`、`src/store.js`
- 依赖：`anime4k-webgpu 1.0.0`（WebGPU 超分）、`axios 1.20.0`、`electron-updater 6.8.9`；开发栈为 `electron 44.9.1` + `electron-builder 26.15.3` + `react ^18.3.1` + `vite ^5.4.11`
- Windows 包把 `build/ffmpeg` 下的 `ffmpeg.exe` / `ffprobe.exe` 作为 `extraResources` 打进产物（合并/转码不依赖外部 FFmpeg）
- 运行要求 `node >=22.12`

## 使用前需要注意

**① 它是社区修改版，不是官方客户端。** 未获红果／西饭／河马平台背书，也不提供付费分集解锁。用它取内容属于"社区工具自行对接来源平台"，**账号、内容版权与平台服务条款的边界都要自己判断**。这一段只作信息记录，不构成使用建议，也不对合规性作定性。

**② Windows EXE 未签名。** README 明写"安装版和便携版 EXE 尚未签名，可能出现系统安全提示"。请自行核对下载来源与 `SHA256SUMS.txt`。

**③ README 的 Mac 签名宣称与构建配置互相矛盾。** README 第 20、30 行称 Mac 正式包"完成 Developer ID 签名、Apple 公证 Accepted 和票据装订"，但仓库 `package.json` 里 mac 的构建配置是 `"identity": "-"`、`"hardenedRuntime": false`、`"notarize": false`——三者都指向"未签名、未公证"。这可能是发布流程在打包后另行签名（我无法验证），但**两处口径不一致这一事实本身值得记下**，装 Mac 版前建议自己确认一下包的签名状态。

**④ 涉及扫码登录与下载平台视频，风险自担。** 4.3 的登录管理会读取你账号的 APP 观看记录；下载得到的是平台视频文件。这两件事的合规性完全取决于你所在地区与平台条款。

**⑤ 未安装、未审计代码。** 以上功能全部来自 README 与配置文件的自述，我没有下载安装包、没有运行、没有审计源码。
