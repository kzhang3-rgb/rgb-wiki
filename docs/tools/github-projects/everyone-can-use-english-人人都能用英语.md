## 核心结论

ZuodaoTech 组织维护的语言学习项目，名字来自 2010 年的书《人人都能用英语》。但仓库现在已经不只是书——它同时装着三样东西：**书稿原文**、2024 年的「一千小时」训练体系文档，以及配套工具 Enjoy（网页版、浏览器插件、桌面版）。

如果只是想读书，直接看 `book/` 目录就行，不需要安装或注册。

## 仓库里有什么

### 1. 书稿 `book/`

2010 年《人人都能用英语》全文，八章加后记，可以直接在 GitHub 上读：

起点、口语、语音、朗读、词典、语法、精读、叮嘱。

### 2. 一千小时（2024）

1000h.org 上的训练体系，README 列出的入口包括简要说明、训练任务、语音塑造、大脑内部、自我训练五部分。

### 3. Enjoy 工具

- **网页版**：enjoy.bot 已上线。
- **浏览器插件**：支持 YouTube 和 Netflix，已在 Chrome Web Store 上架。
- **桌面版**：README 说明会是对网页版的套壳和增强，标注为"即将发布"。

项目自己的一句话定位是："AI 是当今世界上最好的外语老师，Enjoy 做 AI 最好的助教。"

## 使用前需要注意

- 仓库是"书 + 站点 + 工具"的混合体，找书稿认准 `book/` 目录，其余目录与读书无关。
- 许可证是 GPL-3.0，引用或二次分发书稿内容前先确认协议要求。
- 桌面版在 README 里是规划而非现状，别按已发布来理解。
- 更新节奏在放缓：主要目录最后更新集中在 2026 年 2 月到 6 月，README 里最新的实质性说明是 2026-02。
- 我未使用过 Enjoy 工具，也没通读全书，工具效果与内容质量均未验证。
