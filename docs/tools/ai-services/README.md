# AI 服务与模型入口

[返回工具使用](../README.md) · [返回首页](../../../README.md)

收集大模型的官方网站与 API 入口。这个专题只回答一个问题：**我要做某件事，该去哪个官网？**

- 状态：草稿
- 最近核验：2026-11-02（专题结构创建；已收录分类篇：编码 Agent 与开发服务）

## 收录标准

- 只收**官方一手入口**：官方站点或官方 API 控制台。**不收第三方聚合站、镜像站、代购或中转站**——那类最容易失效，也是钓鱼高发区。
- 每条要写清：能做什么、是否开放 API、有无免费额度，以及限制或注意事项。**不只存链接。**
- 不做模型能力排名，也不替官方做效果承诺；能力结论以官方文档为准，并注明来源。
- 价格、免费额度、上下文长度、是否开放 API 属易变信息，**逐条就地标注核验日期**，不写"长期有效"。

## 分类

主维度按**厂商与地区**组织；不属于单一厂商的类别单独成篇。

| 分类 | 覆盖范围 |
| --- | --- |
| 国外厂商 | OpenAI、Anthropic、Google、xAI、Meta、Mistral、Cohere、Perplexity 等 |
| 国内厂商 | DeepSeek、通义千问、Kimi、智谱 GLM、豆包、文心、混元、MiniMax、阶跃星辰等 |
| [编码 Agent 与开发服务](编码Agent与开发服务.md) | 把模型封装成编码助手的产品（CLI / 桌面端 / IDE 插件），如 Command Code、OpenCode |
| 聚合网关 | OpenRouter、SiliconFlow、火山方舟等统一入口（最易失效，需重点标注） |
| 开源权重与本地部署 | Hugging Face、ModelScope，以及本地运行工具；与 GitHub 项目收藏互链 |
| 图像 / 视频 / 语音 | 图像生成、视频生成、语音合成与识别等专用服务 |

## 每篇的结构

各分类页统一使用下面的表格，便于横向比较：

```markdown
| 服务 | 提供方 | 能做什么 | 官网 | 开放 API | 免费额度 / 计费 | 限制与注意 | 核验日期 |
| --- | --- | --- | --- | --- | --- | --- | --- |
```

官网列只填官方域名；无法确认是否为官方域名时，宁可标"待核验"，不要凭印象填写。

## 维护约定

- **核验日期**：本页记录专题的整体核验情况；每个分类页与易变条目各自就地标注。
- **失效与替代**：域名变更、服务下线或无法访问时，保留记录并写明替代入口，不直接删除。
- **双向互链**：有开源权重或开源实现的模型，在本专题与 [GitHub 项目收藏](../github-projects/README.md) 之间互相指路。
- **复查频率**：建议每月复查一次，聚合网关类条目优先级最高。
