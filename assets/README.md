# 图片与附件

[返回首页](../README.md) · [编写准则](../CONTRIBUTING.md)

按文章主题建立附件目录，例如 `assets/spring-transactions/`，文件采用小写英文和连字符命名，例如 `transaction-flow.png`。

- 只保存实际使用的图片与必要附件，不预建示例图片或空目录。
- 正文通过相对路径引用附件；根据正文所在位置计算路径。
- 图片应包含有意义的替代文本，关键结论同时保留在正文中。
- 保存前检查体积、敏感信息和来源授权。
- 不存放视频、大型安装包或未经授权的书籍 PDF。
- 移动或重命名附件时，检查并更新正文引用。
